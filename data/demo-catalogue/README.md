# Demo catalogue photographs

The eight designs that `python manage.py seed_demo_catalogue` puts in the local
database, and that every screenshot and breakpoint sweep under
the screenshots are measured against.

They live here rather than in `media/products/` because `media/` is
gitignored — it is where real uploads go. The seed command copies whichever of
these are missing into `media/products/` before it runs, so a fresh clone
needs nothing but the command.

| file | product |
|---|---|
| `hero-1.jpg` … `hero-4.jpg` | Rampage — the one product with four photographs, so the gallery rail and its arrow keys are exercised by the default data |
| `overdrive.jpg` | Overdrive |
| `asterisk.jpg` | Asterisk |
| `signal.jpg` | Noise / Signal |
| `indeks.jpg` | Indeks 100000 |
| `quyosh.jpg` | Quyosh |
| `halqa.jpg` | Halqa |
| `fade.jpg` | Fade |

These are the Phase 2 garment mockups, not real product photography. Phase 9
owns the image pipeline and Phase 11 the real shots (§19 Q19); until then these
are what the design is judged on, so they stay at the catalogue's 4:5 ratio.
